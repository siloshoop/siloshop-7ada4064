# src architecture rules
- In the Android app, WebView textZoom stays 100% and FontScalePlugin's system fontScale (clamped, src/lib/appFontScale.ts) scales the root font size; fixed text sizes use rem and enlarged-only layout tweaks use the `scaled:` variant, so text, fields and images grow together without changing the normal-size design.
- Canonical tags always use the www production origin: RouteCanonical sets one per path inside BrowserRouter (pages may override), and Android App Links claim both www.siloshop.net and siloshop.net, which requires that no Lovable Primary domain is set (a Primary makes the other host redirect, Android rejects redirecting hosts, and on Android 11 and older one failed host cancels all).
- Auth email return links use getAuthRedirectOrigin: the visitor's own live host (www or bare siloshop.net, both allowed return addresses) and www elsewhere, so recovery sessions land on the address the visitor used.
- Show public Storage photos through src/lib/imageUrl.ts (resized render copies with srcset and original-file fallback); full-screen zoom keeps the original so detail is never lost.
- Bundle the Cairo font via @fontsource-variable (no Google Fonts link) so first paint never waits on a third-party host and the Android app needs no font download.
- useCompareProducts shares only in-flight account reads and drops them on every saved change; completed lists are never reused.
